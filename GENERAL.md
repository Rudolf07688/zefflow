# Project
Building an agentic script/workflow that will interrogate the current repository and draw out maps and notes in an easy to read way. 
- Read this/these documents and you wil understand EVERYTHING that's going on. 

## Requirements
- Must demonstrate project structure 
  - Examples: ["it's a mono repo", "Here are the webapp files and here are the python backend files", ...] etc.
- Must link modules and libraries together visually.
- Must map dirs -> responsibilities.
- Must identify most important dependancies. 
- If local dev environment is present - find out how to get it going for the user.
- If testing scripts are present - imform the user how to run them.

## Other
- Each repository is different - use your own judgement in terms of how to explain this specific repo best.
- Mermaid diagrams can be nice for simple mappings.
- Use your imagination.
